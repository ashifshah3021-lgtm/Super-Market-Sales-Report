# Supermarket Sales Analysis

## Overview

This analysis explores supermarket transaction data, focusing on sales trends, customer and payment patterns, product performance, and city-level results.

- **Transactions analyzed:** 500
- **Reporting period:** 2026-01-01 to 2026-07-01
- **Total sales:** 244,411.08

## Key Findings

- **Highest-sales month:** 2026-04 (52,569.77)
- **Lowest-sales month:** 2026-07 (3,467.44)
- **Highest-sales category:** Beverages (56,108.24)
- **Top product overall:** Cheese (27,906.30)
- **Most common customer type:** Member (296 transactions)
- **Most-used payment method:** UPI (127 transactions, 25.4%)
